Project Three

This project entails hardware and software, in which we have built a automatic food dispenser and shelter for cats. It's fully powered by solar panel, which charges the battery inside the shelter, and there are sensors that see if theres and cat entering the shelter, and it detects using YOLOv* model. After a cat is detected, the food dispenser would first check if there is any food left inside the bowl, if not, it'll start dispensing food and heater will aslo start functioning. All code were embedded into a ESP32, and sensor corresponding is also through that as well. Power control is through PCB.
